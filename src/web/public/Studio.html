One recording or two?

One recording (pattern mode) — dynamic values are found by their shape and by tracing them back to an earlier response. Quick to start.

Two recordings (diff mode) — record the same journey twice with different data. Every value that changes between the two is found: the deepest and most reliable correlation.

Should I include Img / CSS / JS / Font?
  • Leave them out (default) for server / API load. On replay only the images and stylesheets named in the page HTML are downloaded (VuGen Mode=HTML, DevWeb downloadHtmlStaticResources).
  • Select them (or All) for realistic page load, and always for JavaScript-based apps (React, Angular, Vue…): script files, and files that JavaScript or CSS requests — lazy-loaded code, fonts, images on later screens — are not downloaded from the HTML, so they are only downloaded if they are in the script.
Included files are added to the page step that loaded them (EXTRARES / resources[]), never as separate requests and never twice. Known analytics/ads domains are always left out here. VuGen also needs the run-time setting Download non-HTML resources on (default).
