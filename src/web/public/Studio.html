In the script Leave out
Should I include Img / CSS / JS / Font?
  • Leave them out (default) for server / API load. On replay only the images and stylesheets named in the page HTML are downloaded (VuGen Mode=HTML, DevWeb downloadHtmlStaticResources).
  • Select them (or All) for realistic page load, and always for JavaScript-based apps (React, Angular, Vue…): script files, and files that JavaScript or CSS requests — lazy-loaded code, fonts, images on later screens — are not downloaded from the HTML, so they are only downloaded if they are in the script.
Included files are added to the page step that loaded them (EXTRARES / resources[]), never as separate requests and never twice. Known analytics/ads domains are always left out here unless you untick Analytics / ads. VuGen also needs the run-time setting Download non-HTML resources on (default).

 Pop-ups, new tabs, or DevTools / bookmarks blocked? Use the CDP Recorder

                
A small Windows program that records your whole journey — including every new tab and pop-up window (for example a sign-in pop-up) — and names transactions from a floating toolbar. No DevTools, no bookmarks and no browser extension needed.

                
Set up once on this computer

                
    
                  
  1. Download cdp-recorder.zip (one time only — and again when this page says a newer version is available)
    2. 
                  
  2. Right-click the ZIP → Extract All… → choose a folder that stays and where your computer lets you run programs, for example C:\PerfX\cdp-recorder — not inside your user profile folder (such as Downloads, Desktop or Documents)
    3. 
                  
  3. Open the extracted folder and double-click cdp-recorder.exe once. This connects it to the Start recording button for your Windows user — no administrator rights needed. It opens a small toolbar and a browser window; you don't need to record anything in them. If you move the folder later, double-click it again
    4. 
                

                
Record

                
    
                  
  1. Click Start recording above, type your application's address, choose Edge or Chrome and, if you like, a private window, then click Start recording. The first time, your browser asks "Open cdp-recorder?" — click Open
    2. 
                  
  2. Two windows open: a small toolbar and an orange-bordered RECORDING window showing your application. Use your application only in the recording window (and the tabs and pop-ups it opens) — your normal browser is not recorded
    3. 
                  
  3. Name each transaction on this page: type a name (e.g. Login) and press Enter — the running transaction ends and this one starts, numbered for you (T02_Login). With planned steps (More options), press Enter on an empty box for the next one. End ends the running one. The page title is offered as grey text — Tab takes it. Rename a transaction with the pencil in the list; Undo last mark takes back the last Start or End. On the toolbar: type a name, click Start Transaction, do the steps, then click End Transaction
    4. 
                  
  4. Click Stop and save — the .har file is saved in your Downloads folder and opens here, with the script ready. The toolbar says it is saved; the recorder's windows close after 10 seconds (Keep open on the toolbar keeps them)
    5. 
                

                
Transactions named on the toolbar are picked up automatically — no START/END bookmarks needed. Don't run cdp-recorder.exe from inside the ZIP: Windows would run it from a temporary folder and the button could not find it next time.

                
Or start it yourself

                
    
                  
  1. Double-click cdp-recorder.exe. Two windows open: a small toolbar and an orange-bordered RECORDING window. Use your application only in the recording window — your normal browser is not recorded
    2. 
                  
  2. On the toolbar click Start Recording, type a transaction name (e.g. T01_Login) and click Start Transaction
    3. 
                  
  3. Do the steps for that transaction, then click End Transaction. Repeat for each transaction
    4. 
                  
  4. Click Stop Recording — the .har file is saved in the same folder as cdp-recorder.exe. Drop it in the area above
    5. 
                

              

            


            
            

              

                

                  
 Install the transaction bookmarks (one-time setup)

                  
Show the Bookmarks Bar (Ctrl+Shift+B), then drag both buttons below onto it. During recording, click START Transaction before each transaction and END Transaction after. A prompt lets you type the transaction name each time.

                  

                    ▶ START Transaction
                    ■ END Transaction
                  

                  
How it works: the last used transaction name is remembered automatically — the END prompt pre-fills with the same name you used for START. Both bookmarks fire a request to a .invalid domain which appears in the HAR and is detected as a transaction marker by this tool.

                  
Bookmarklets only work on real websites. They will not respond on the browser's New Tab page or any chrome:// page — Chrome blocks them silently. Always navigate to your application URL first, then click the bookmark.

                

                

                  
 Record your application

                  
    
                    
  1. Navigate to your application in the browser (e.g. https://myapp.example.com)
    2. 
                    
  2. Press F12 → click the Network tab → enable Preserve Log and Disable Cache checkboxes → click  to clear existing entries
    3. 
                    
  3. Click the START Transaction bookmark — type a name (e.g. T01_Login) and click OK
    4. 
                    
  4. Perform all steps for that transaction (login, fill form, navigate, etc.)
    5. 
                    
  5. Click the END Transaction bookmark — the name is pre-filled from START, just click OK
    6. 
                    
  6. Repeat START / END for each transaction (T02_Home, T03_Search…). Navigate freely between bookmarklet clicks — markers always fire in the current page's context
    7. 
                    
  7. After all transactions are done: in the Network tab, click the download icon → select "Export HAR (with sensitive data)" — or right-click any row → "Save all as HAR with content"
    8. 
                    
  8. Drop the saved .har file in the area above — the script is generated at once, in the format you chose
    9. 
                  

                

              

              

                

                  
 Required: enable "Allow to generate HAR with Sensitive Data" before recording

                  
    
                    
  1. Press F12 to open DevTools → click the Settings gear icon (top-right corner) — or press F1 / Shift+?
    2. 
                    
  2. Scroll to the Network section
    3. 
                    
  3. Tick "Allow to generate HAR with Sensitive Data"
    4. 
                    
  4. Close Settings → when downloading, choose "Export HAR (with sensitive data)"
    5. 
                  

                  
This ensures Authorization headers, cookies and Bearer tokens are included. NFT environments use test data only — safe to enable.

                

                

                  
 DevTools settings (required before recording)

                  
    
                    
  • Preserve Log — keeps all network requests visible across page navigations and redirects. Without this, requests from login redirects are lost.
    • 
                    
  • Disable Cache — forces the browser to fetch fresh responses instead of using the local cache. Without this, response bodies may be empty in the HAR, making correlation extraction impossible in Script Studio.
    • 
                  

                  
Both checkboxes are in the Network tab toolbar at the top of the DevTools panel.

                  
Forgot markers? After opening the HAR, tick the requests in the Requests list and use New transaction to group them into transactions.

                  
Keep the Developer Tools (F12) open for the entire recording session. Closing it loses all recorded data.
