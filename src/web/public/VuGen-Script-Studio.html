📖 Help & Feature Guide
⚡ Quick Start
  1. Drop a .har file onto the upload zone (record with Chrome DevTools → Network → Export HAR)
  2. Optionally add a 2nd HAR recording for diff-mode correlation (more accurate)
  3. Select output format: DevWeb (JavaScript) or Web HTTP/HTML (VuGen C)
  4. Click ⚡ Analyze — scripts are generated instantly
  5. Review correlations, add more if needed, then Download ZIP
🔍 Correlation Advisor

The Advisor automatically detects values that flow from a response into later requests (session IDs, tokens, CSRF values, etc.). Each candidate is shown as a card with confidence and context.

HighValue traced: response → request exactly
MedJWT or UUID pattern detected by shape

Click Accept on a card to add it as a correlation. Click ▶ Apply & Regenerate to rebuild the script.

🚦 Request Inspector — Traffic Light Highlighting

Expand the Request Inspector section inside the Advisor panel, then pick any request from the dropdown.

Green — value traced to a prior response. Click Trace to see which, or + Correlate to add immediately.
Yellow — looks dynamic (JWT / UUID / token) but source not found in this HAR. Use Paste & Detect to create a correlation.

The inspector scans headers, body fields, query string params, and URL path segments (e.g. /api/resources/286522 → session ID).

📋 Paste & Detect

Click the Paste & Detect button in the Advisor header. Use it when you have a server response that isn't in the HAR, or when you want to manually specify an extractor.

  1. Paste the response body — JSON, HTML, XML, or plain text (or leave empty)
  2. Enter the value to extract — paste the exact string you want to capture
  3. Click Detect & Generate — the tool auto-selects the best extractor type
  4. If multiple JSON paths are found, pick the correct one from the radio list
  5. If the value appears multiple times in the response, choose the right occurrence
  6. If the response is empty, a shape-based pattern is generated automatically (JWT regex, UUID regex, etc.)

🔗 URL Path Parameters

Values embedded in URL paths (e.g. /scfm/alert_tuned/LIVE/286522) are detected and replaced automatically when you add a correlation for that value. The generated script will use ${load.global.sessionId} (DevWeb) or {sessionId} (VuGen) in place of the hard-coded value.

🧪 Diff Mode vs Pattern Mode
Pattern Mode (1 HAR) — detects values by scanning each response for values that appear in later requests. Works for most cases.
Diff Mode (2 HARs) — compares two recordings to find values that differ between runs (true dynamic values). More accurate, fewer false positives.
🎛️ Request Filters

Filters run before analysis. By default only Fetch/XHR and Document requests are included — CSS, JS, fonts, and images are excluded as they are not relevant to load testing. Use All to add them back.
