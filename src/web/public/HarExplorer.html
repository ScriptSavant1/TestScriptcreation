Find where every dynamic value comes from

Open a recording, click any request to see its headers, payload and response, and look up any value: where the server first sent it, every request that sends it back, and what to do in the script — then correlate it in one click.

Drop a .har file here

From the PerfX CDP Recorder, the bookmarks + DevTools recording, or a HAR file a client sent you.

  1. 1See every requestGrouped by transaction, like the Recorder. Headers, payload, response, cookies and timing.
  2. 2Find a valueType it, pick a suggestion, or select it in a response. Encoded forms are found too.
  3. 3Correlate itThe extractor is built for VuGen or DevWeb — continue in Script Studio with it added.

When to use it

  • A replay fails on a value — see where the server sent it and where it goes next
  • The Correlation Advisor missed one — find it here, correlate it, done
  • A value never comes back from the server — it is typed (a parameter) or made by the browser (generate it in the script)
  • Values sent encoded — URL-encoded, JSON-escaped, Base64 or HTML entities are matched to the original

The file is read in your browser — nothing is uploaded.
