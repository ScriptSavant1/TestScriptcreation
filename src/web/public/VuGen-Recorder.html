🔖 Step 1 — Install Transaction Bookmarks (one-time setup)

Show the Bookmarks Bar (Ctrl+Shift+B), then drag both buttons below onto it. During recording, click ▶ START Transaction before each transaction and ■ END Transaction after. A prompt lets you type the transaction name each time.

▶ START Transaction ■ END Transaction
How it works: The last used transaction name is remembered automatically — the END prompt pre-fills with the same name you used for START. Both bookmarks fire a request to a .invalid domain which appears in the HAR and is detected as a transaction marker by this tool.
⚠ Bookmarklets only work on real websites. They will not respond on the browser’s New Tab page or any chrome:// page — Chrome blocks them silently. Always navigate to your application URL first, then click the bookmark.

📋 Step 2 — Record Your Application

  1. Navigate to your application in the browser (e.g. https://myapp.company.com)
  2. Press F12 → click the Network tab → enable Preserve Log and Disable Cache checkboxes → click 🚫 to clear existing entries
  3. Click the ▶ START Transaction bookmark — type a name (e.g. T01_Login) and click OK
  4. Perform all steps for that transaction (login, fill form, navigate, etc.)
  5. Click the ■ END Transaction bookmark — the name is pre-filled from START, just click OK
  6. Repeat START / END for each transaction (T02_Home, T03_Search…). Navigate freely between bookmarklet clicks — markers always fire in the current page’s context
  7. After all transactions are done: in the Network tab, click the download icon → select "Export HAR (with sensitive data)" — or right-click any row → "Save all as HAR with content"
  8. Drop the saved .har file in the area above — both scripts are generated automatically
🔒 Required: Enable "Allow to generate HAR with Sensitive Data" before recording
  1. Press F12 to open DevTools → click the Settings gear icon (top-right corner) — or press F1 / Shift+?
  2. Scroll to the Network section
  3. Tick "Allow to generate HAR with Sensitive Data"
  4. Close Settings → when downloading, choose "Export HAR (with sensitive data)"
This ensures Authorization headers, cookies and Bearer tokens are included. NFT environments use test data only — safe to enable.
💡 DevTools settings (required before recording):
  • Preserve Log — keeps all network requests visible across page navigations and redirects. Without this, requests from login redirects are lost.
  • Disable Cache — forces the browser to fetch fresh responses instead of using the local cache. Without this, response bodies may be empty in the HAR, making correlation extraction impossible in Script Studio.
Both checkboxes are in the Network tab toolbar at the top of the DevTools panel.
💡 Forgot markers? Use Select Mode after loading the HAR to manually group requests into transactions.
⚠ Keep the Developer Tools (F12) open for the entire recording session. Closing it loses all recorded data.
🔗 Alternative: Address Bar Method (if bookmarklets are blocked by your organisation)
  1. In the browser address bar, type https://START-T01-Login.invalid and press Enter (error page is expected)
  2. Type your application URL to go back, then perform all steps for this transaction
  3. Type https://END-T01-Login.invalid in the address bar and press Enter
  4. Do not click the Back button — type the next START URL directly in the address bar
  5. Repeat for each transaction (T02, T03 etc.)
🪟 Multi-tab / Popup recording — use chrome://net-export/ when your app opens new windows or tabs

Developer Tools (F12) only records the tab it is attached to. If your app opens popup windows or new tabs, use Chrome/Edge's built-in all-tab capture instead. Note: NetLog does not capture POST request bodies - those requests will show a TODO comment in the generated script.

  1. In the Chrome/Edge address bar, navigate to chrome://net-export/
  2. Click Start Logging to Disk — choose a save location and click Save
  3. Open your application in a new tab (the net-export tab stays open in the background)
  4. Use the ▶ START Transaction and ■ END Transaction bookmarks as normal — they fire from any tab and are captured by NetLog
  5. Complete your full user journey (including any popup windows or new tabs the app opens)
  6. Switch back to the chrome://net-export/ tab and click Stop Logging
  7. Drop the saved .json file into this tool just as you would a .har file
POST bodies will show as TODO in generated scripts. Open DevTools alongside for the same session if you also need bodies - then use the .har from DevTools for a complete script.
