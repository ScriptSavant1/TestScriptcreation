CDP Recorder: User Guide

Record a browser journey as a HAR file for the PerfX Studio Recorder and Script Studio — started from PerfX Studio or on its own, without installing a browser extension. Updated {{date}}.

In short
  1. Once: download cdp-recorder.zip from the PerfX Studio Recorder page, extract it to a folder that stays, and double-click cdp-recorder.exe once.
  2. In PerfX Studio, Recorder → Start recording (or Script Studio → Record a new journey): type your application's address, choose Edge or Chrome, click Start recording.
  3. Two windows open: an orange recording window on your application, already recording, and a small toolbar. Do your steps in the recording window.
  4. Name each step: Start Transaction … End Transaction, on the toolbar or the page. The page shows every request as it happens.
  5. Click Stop and save. The HAR is saved to your Downloads folder and opens in PerfX Studio by itself.

You can still start cdp-recorder.exe yourself and record from its toolbar — see section 4.

1. What it is

CDP Recorder is a single program (cdp-recorder.exe) that records everything your browser sends and receives while you use an application, including new tabs and pop-ups, and saves it as a HAR file. Script Studio turns that HAR into a DevWeb or VuGen Web HTTP/HTML script.

You don't need a browser extension or administrator rights, and you don't need to open DevTools (F12) either.

2. Set it up once

In PerfX Studio, open the Recorder page and download cdp-recorder.zip (under How to record your journey, or quick search → Get CDP Recorder).

Right-click the ZIP, choose Extract All…, and extract it to a folder that stays and where your computer lets you run programs, such as C:\PerfX\cdp-recorder — not inside your user profile folder (such as Downloads, Desktop or Documents). If Windows blocks the program there, ask your IT team. Then open that folder and double-click cdp-recorder.exe once. That connects it to the Start recording buttons in PerfX Studio for your Windows user — no administrator rights needed. It then opens its two windows as in section 4; you don't need to record anything in them — leave them open or click Quit.

Extract it first — and double-click it onceDon't double-click cdp-recorder.exe while it is still inside the ZIP. Windows runs it from a temporary folder, the Start recording button cannot find it there next time, and recordings you start yourself end up there. Extracting alone is not enough: the double-click is what sets it up. If you move the folder later, double-click it again.
Nothing is installedIt's a single program. It runs on your PC only, and nothing you record is sent to the PerfX server.

When PerfX Studio has a newer version, the Recorder page says "A newer CDP Recorder is available": download the ZIP again and extract it over the old folder.

3. Record from PerfX Studio

1

Recorder → Start recording

The card says whether the CDP Recorder is ready on your PC. Either way, click Start recording — PerfX Studio starts it when needed.

2

Type the address, choose the browser, click Start recording

Open an InPrivate window (Incognito in Chrome) is optional — untick it if your application does not work in a private window. Either way the recording window starts signed out, in a fresh browser profile, so the login is recorded too. Under More options, a recording name becomes the file name, and a first transaction starts as soon as the page opens. The file name in Downloads is shown at the bottom.

"Open cdp-recorder?"When the CDP Recorder is not running yet, your browser asks whether this site may open it. Click Open. It then waits in the background, so the next recording starts straight away; it closes itself after an hour without use. If nothing answers, the window shows the set-up steps — see section 2.
Started it yourself? Click Allow on the toolbarSome computers do not let the browser start programs. Then start cdp-recorder.exe yourself first and click Start recording on the page: the small toolbar asks Allow this page to start recordings? and names the PerfX Studio address — click Allow, and the recording starts by itself. It asks once per address and remembers it on this computer. Don't allow if you did not just click Start recording.
3

Record in the orange window — the page shows what is recorded

The recording window opens on your application, already recording, with the toolbar beside it — as with VuGen. Do your steps there; new tabs and pop-ups it opens are recorded too. The page shows every request as it happens, grouped by transaction: the current one open, earlier ones folded; images, style sheets, scripts and fonts, and background calls, folded into one line each; requests from pop-ups and new tabs marked window 2, window 3.

4

Name transactions — on the toolbar or on the page

Type a name, Start Transaction, do the step, End Transaction — the same as in section 5. Starting the next transaction ends the open one, and so does Stop.

5

Stop and save

Click Stop and save on the page (or Stop Recording on the toolbar). The HAR is saved to your Downloads folder as <name>_<date>_<time>.har, and the Recorder opens the file: choose the script format and carry on. The toolbar says the recording is saved, and the two recorder windows close after 10 seconds — click Keep open to look at the recording window first, or Close windows to close them now.

From Script Studio

Script Studio → Record a new journey → Start recording works the same way. The recording loads as Recording 1; record the same journey again with different data and it loads as Recording 2 (diff mode — the deepest correlation). Then choose the format and click Analyse & generate.

4. Or start it yourself

Not using PerfX Studio's Start recording? Double-click cdp-recorder.exe. After a few seconds two windows open:

Use only the recording windowYour usual browser window is not recorded, even if it's the same browser. If you click around in your normal browser, the recording comes out empty. The recording window uses its own temporary profile, so you may need to log in to your application again there.

5. Record your journey

1

Click Start Recording, then wait for "Settled"

The toolbar shows two counters and, once it's ready, a green "Settled — safe to start a transaction" line. This usually takes a second or two, but can take up to about 20 seconds on a slow or heavily managed PC. Start Transaction stays greyed out until then.

2

Name your transaction and click Start Transaction

Type a short name for the business step, such as Login, Search or Checkout. Each transaction becomes a timed transaction in your script. You can also press Enter instead of clicking.

3

Do the step in the recording window

The toolbar badge now reads Recording — Login. Go to the recording window, type your application's address in its address bar, and carry out the step.

Active counts requests still in progress. Background counts repeating "heartbeat" calls the app makes on its own; these are kept separate.

4

Click End Transaction, then repeat for the next step

Wait until the page has finished loading (Active back to 0), then click End Transaction. Name the next step and start it. Finished transactions are listed under Completed transactions.

New tabs and pop-ups are recorded tooIf a link opens a new tab or a sign-in pop-up, keep going in that tab. It belongs to the recording window and its traffic is captured in the current transaction.

Tips for a clean recording

  • One business step per transaction. Don't put a whole journey in one transaction.
  • Start the transaction before you click, and end it after the page has loaded.
  • Close other tabs in the recording window that you don't need, so their traffic doesn't end up in your transactions.

6. The orange "no requests" warning

If a transaction ends without recording a single request, the toolbar shows this straight away:

Almost always this means the clicks happened in a different browser window. Switch to the window with the orange "This is the RECORDING window" page (or a tab it opened) and do that step again as a new transaction.

An empty transaction is left out when Script Studio builds your script, so it does no harm. It just won't be there.

7. Stop and save

Click Stop Recording. The toolbar asks for a file name (the default is recording.har) — type one and click Save. The toolbar then shows Recording complete with the number of requests captured. (A recording started from PerfX Studio is not asked: it is saved to Downloads under the name chosen there.)

Where your file is:

  • Saved automatically in the same folder as cdp-recorder.exe.
  • Download HAR saves another copy through your browser, usually to your Downloads folder.

To record again, click New Recording or Start Recording. If the toolbar gets long, scroll it.

8. Open it in Script Studio

In PerfX Studio, open Script Studio, drop your HAR into Recording 1, choose DevWeb or Web HTTP/HTML, and click Analyze & Generate.

"Responses have empty bodies" warningScript Studio may say that some responses have empty bodies and suggest re-recording with DevTools' "Disable cache". For CDP Recorder files you can ignore this when it's about images, styles or scripts: the recorder deliberately keeps response bodies only for pages and API calls, which is what correlation needs.

9. Finish up

Click Quit on the toolbar. This closes both windows and deletes the temporary browser profile, including anything you logged in to during the session. Your HAR files are kept. A recording that is still running is saved first — to Downloads when it was started from PerfX Studio, otherwise next to the .exe — so Quit never loses a recording.

When you record from PerfX Studio you don't need to Quit: after Stop and save the recorder closes its windows by itself after a 10-second countdown on the toolbar (Keep open keeps them), waits in the background for the next recording, and closes itself after an hour without use.

10. Use Chrome instead of Edge

Recording from PerfX Studio? Just choose Google Chrome in the Start recording window. When you start the recorder yourself, it uses Microsoft Edge by default and falls back to Chrome only if Edge can't be used. To use Chrome that way, make a shortcut once:

  1. Right-click cdp-recorder.exe → Show more options → Create shortcut.
  2. Right-click the new shortcut → Properties.
  3. In Target, add --browser chrome after the closing quote: 
    "C:\PerfX\Recordings\cdp-recorder.exe" --browser chrome
  4. Click OK and rename it, for example CDP Recorder (Chrome).

Double-click the shortcut whenever you want Chrome. Double-clicking the .exe itself still opens Edge.

If you then see "No Chrome install found", Chrome is installed somewhere non-standard (for example under your user profile). Ask your support team, or see Command-line options.

11. Your data

  • Everything runs on your PC. Recordings are saved only to your disk. Nothing is uploaded to the PerfX server.
  • Values of request fields whose names look like passwords, PINs, CVVs or secrets are replaced with a placeholder.
  • Cookies, sign-in tokens (Authorization headers) and response content are kept in full, because Script Studio needs them to find dynamic values.
  • The temporary browser profile is deleted when you click Quit (and after each recording started from PerfX Studio).
  • The recorder's small control service answers only on your own PC, and only to its toolbar and to the PerfX Studio page that started it. Other web sites cannot read your recordings through it.
Treat HAR files as sensitiveA HAR can contain live session tokens and personal data from the application. Record with test accounts, store HARs in an approved location, and delete them when you've finished.

13. Command-line options

For a shortcut's Target, or a Command Prompt in the recorder's folder:

OptionWhat it does
--browser chrome
--browser edge		Choose the browser. The default tries Edge first, then Chrome.
--profile C:\PerfX\profileKeep the recording window's profile in this folder between runs, so you stay logged in. It is not deleted on Quit.
--real-profileUse your own everyday Edge profile (bookmarks, saved logins). Close every Edge window first, or it won't start.
--out C:\PerfX\HARsSave recordings to this folder instead of the recorder's own folder.
--portal "…"Used by PerfX Studio's Start recording — not typed by hand.
--ui-port 8787
--cdp-port 9333		Change the local ports used, if something else already uses them. Rarely needed: the recording browser picks a free port by itself unless you set --cdp-port.

If the browser is installed in a non-standard location, tell the recorder where it is before starting it, for example:

set CHROME_PATH=C:\Users\you\AppData\Local\Google\Chrome\Application\chrome.exe
cdp-recorder.exe --browser chrome

(EDGE_PATH works the same way for Edge.)
