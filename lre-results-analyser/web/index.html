Analyse a LoadRunner Enterprise run

Pick the run's raw results folder or ZIP. Transaction statistics, steady state, workload, errors and insights are computed from RawData.eve and the scenario files — independently of LRE Analysis — and can be exported to Excel, Word and PDF.

or drop the folder / ZIP here

What is read

  • RawData.eve — every transaction sample (required)
  • res*.lrr, RunInfo.ini, _t_rep.eve, RawData.map — run, schedule, VUsers (required)
  • *.usp / *.cfg / *.usr — pacing, think time, transactions per script
  • SqliteDb.db — errors · sum_data/ — LG CPU, HTTP codes, pass/fail

Very large runs

Any size works here — the file is streamed. For runs of hundreds of GB the command line is faster and can run on a server or LG with the files:

node lre-results-analyser/cli/analyse.js "D:\Results\Run_59" --xlsx run59.xlsx --html run59.html
