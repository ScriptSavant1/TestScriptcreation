  VUGEN FILE 1: Action.c (main requests, grouped by folder/transaction)
================================================================================

```c
Action()
{
    web_set_sockets_option("SSL_VERSION", "AUTO");

    // ---- Authentication (Transaction T01) ----
    lr_start_transaction("T01_Authentication");

    // Correlation registration BEFORE the producing request:
    web_reg_save_param_json("accessToken",
        "QueryString=$.access_token",
        "Ord=1",
        LAST);

    web_add_header("Content-Type", "application/x-www-form-urlencoded");

    web_custom_request("Login",
        "URL={url}/oauth2/token",
        "Method=POST",
        "Resource=0",
        "RecContentType=application/json",
        "Referer=",
        "Snapshot=t1.inf",
        "Mode=HTML",
        "EncType=application/x-www-form-urlencoded",
        "Body=grant_type=password&client_id={clientId}&client_secret={clientSecret}&username={username}&password={password}",
        LAST);

    lr_end_transaction("T01_Authentication", LR_AUTO);
    lr_think_time(1);

    // ---- Users (Transaction T02) ----
    lr_start_transaction("T02_Users");

    web_add_header("Authorization", "Bearer {accessToken}");
    web_add_header("Content-Type", "application/json");

    web_url("Get Users",
        "URL={url}/api/v2/users",
        "Resource=0",
        "RecContentType=application/json",
        "Referer=",
        "Snapshot=t2.inf",
        "Mode=HTML",
        LAST);

    lr_end_transaction("T02_Users", LR_AUTO);
    lr_think_time(1);

    return 0;
}
```

RULES for Action.c:
- `web_set_sockets_option("SSL_VERSION", "AUTO")` is ALWAYS the first line
- Each top-level collection folder becomes one transaction: T01_FolderName, T02_FolderName
- `web_reg_save_param_json/regexp` MUST appear BEFORE the request that produces the value
- `web_add_header()` applies to the NEXT request only — call before each request that needs headers
- `{varName}` is VuGen parameter syntax — replaces `{{varName}}` from collection
- `{accessToken}` for correlation targets (also use {varName} — LR stores correlations as params)
- `"Snapshot=tN.inf"` is REQUIRED in EVERY web_url() and web_custom_request() — place it
  immediately before `"Mode=HTML"`. N increments globally: t1, t2, t3... across the whole script
- GET requests → `web_url()`, all other methods → `web_custom_request()`
- `lr_think_time(1)` after each transaction end
- Function ends with `return 0;`

CORRELATION FUNCTIONS (place BEFORE the producing request):

JSON path extraction:
```c
web_reg_save_param_json("paramName",
    "QueryString=$.json.path",
    "Ord=1",
    LAST);
```

Boundary extraction:
```c
web_reg_save_param("paramName",
    "LB=<leftBoundary>",
    "RB=<rightBoundary>",
    "Ord=1",
    LAST);
```

Regexp extraction:
```c
web_reg_save_param_regexp("paramName",
    "RegExp=<pattern>",
    "Ord=1",
    LAST);
```

HTTP FUNCTION REFERENCE:

GET request:
```c
web_url("Request Name",
    "URL={baseUrl}/path/{resourceId}",
    "Resource=0",
    "RecContentType=application/json",
    "Referer=",
    "Snapshot=t1.inf",
    "Mode=HTML",
    LAST);
```

POST/PUT/PATCH/DELETE with JSON body:
```c
web_custom_request("Request Name",
    "URL={baseUrl}/api/endpoint",
    "Method=POST",
    "Resource=0",
    "RecContentType=application/json",
    "Referer=",
    "Snapshot=t2.inf",
    "Mode=HTML",
    "EncType=application/json",
    "Body={\"username\":\"{username}\",\"password\":\"{password}\"}",

```

POST with URL-encoded body:
```c
web_custom_request("Token Request",
    "URL={url}/oauth/token",
    "Method=POST",
    "Resource=0",
    "RecContentType=application/json",
    "Referer=",
    "Snapshot=t3.inf",
    "Mode=HTML",
    "EncType=application/x-www-form-urlencoded",
    "Body=grant_type=client_credentials&client_id={clientId}&client_secret={clientSecret}",

```

NOTE: "Snapshot=tN.inf" is REQUIRED in every web_url() and web_custom_request() call.
N starts at 1 and increments globally across all requests in Action.c (t1, t2, t3...).
Place it immediately BEFORE "Mode=HTML".

CRITICAL: VuGen uses INI-style [parameter:name] sections, NOT XML.
Each section maps one {paramName} in C code to a column in collection_data.dat.

Classification:
  nextValue: once      → GenerateNewVal="Once"          (config: URL, clientId, API keys)
  nextValue: iteration → GenerateNewVal="EachIteration"  (test data: username, password)

================================================================================
  PARAMETER MAPPING: DevWeb (JS) vs Web HTTP/HTML (C)
================================================================================

  +---------------------+-----------------------------+-----------------------------+
  | Aspect              | DevWeb (JavaScript)          | Web HTTP/HTML (C)           |
  +---------------------+-----------------------------+-----------------------------+
  | Config param        | ${load.params.baseUrl}       | {baseUrl}                   |
  | Dynamic/corr. value | ${load.global.accessToken}   | {accessToken}               |
  | Think time          | load.thinkTime(1)            | lr_think_time(1)            |
  | Transaction start   | TS01.start()                 | lr_start_transaction("T01") |
  | Transaction stop    | TS01.stop(Passed)            | lr_end_transaction("T01",   |
  |                     |                             |   LR_AUTO)                  |
  | GET request         | new load.WebRequest({...})   | web_url("name",...,LAST)    |
  | POST request        | new load.WebRequest({...})   | web_custom_request("name",  |
  |                     |                             |   "Method=POST",...,LAST)   |
  | Header              | headers: {key: value}        | web_add_header("k","v")     |
  | Log                 | load.log("msg",info)         | lr_output_message("msg")    |
  | JSON correlation    | new load.JsonPathExtractor() | web_reg_save_param_json()   |
  | Boundary corr.      | new load.BoundaryExtractor() | web_reg_save_param()        |
  | Regexp corr.        | new load.RegexpExtractor()   | web_reg_save_param_regexp() |
  | Config file ext.    | .csv                         | .dat                        |
  | Parameter syntax    | ${load.params.name}          | {name}                      |
  +---------------------+-----------------------------+-----------------------------+

IMPORTANT: In Web HTTP/HTML, ALL variables (static config, test data, correlations)
use the same {varName} syntax. There is no load.global / load.params distinction.
Correlation values are stored as LR parameters automatically by web_reg_save_param_*.
