Workload Modeller

From the load you need to an LRE scenario

Tell it what each script must reach — transactions per second (TPS), transactions per hour, or a number of virtual users (Vusers) — and which machines run the test. The modeller works out Vusers, pacing, ramp-up and ramp-down, load generators, TPS and iterations, warns when something cannot work, and gives the LRE settings to copy and an Excel workbook.

Load generators

The machines that run the Vusers (load generators). Choose the machine type — the on-premise Windows servers or AWS c6a.4xlarge (Linux or Windows); “Another machine” is for a project with its own load generators. Add a pool when a test uses two kinds, for example on-premise and AWS. Vusers per machine is the smallest of the team rule (web pages / API calls, read from each script), the machine’s CPU and its memory; a figure from a past run is better if you have one.
