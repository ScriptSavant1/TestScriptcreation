PerfX Studio — IIS Deployment Guide

Step-by-step instructions for installing PerfX Studio on Windows Server + IIS. Complete every step in order — each step tells you exactly what to click or type.

v2.8.0 July 2026 Windows Server 2019 / 2022 IIS 10 + iisnode Node.js 18 LTS
BEFORE YOU START

Prerequisites Checklist

!
The IIS server has no internet access

All installers must be downloaded on your local machine and transferred to the server via file share or shared drive before you begin.

Must be installed on the IIS server

  • Windows Server 2019 or 2022With IIS enabled as a Windows Feature
  • Node.js 18 LTSDownload node-v18.x.x-x64.msi on your local machine from nodejs.org, copy to server, run installer there.
  • IIS URL Rewrite Module 2.1Download rewrite_amd64_en-US.msi on your local machine from Microsoft IIS downloads, copy to server, run installer there. Without this, all pages return 404.
  • iisnode v0.2.26Download iisnode-full-v0.2.26-x64.msi on your local machine from GitHub (Azure/iisnode Releases), copy to server, run installer there.
  • Administrator access on the serverRequired to run commands and open IIS Manager.

Must be installed on your local developer machine (VCSE)

  • Node.js 18 LTS — same version as the serverRequired to run npm install in Step 5. Version must match the server exactly or native modules will fail.
  • PerfX Studio source codeTo build node_modules and prepare deployment files.

STEP 1 OF 11

Install Node.js 18 LTS

Node.js is the engine that runs the application. The server has no internet access, so download the installer on your local machine and copy it to the server first.

!
Download on local machine, install on server

The IIS server cannot access nodejs.org. Download node-v18.x.x-x64.msi on your local machine, copy it to the server via file share, then run it there.

  1. On your local machine, go to nodejs.org and download "18.x.x LTS" (file: node-v18.x.x-x64.msi). Do not choose version 20 or 22.
  2. Copy the .msi file to the IIS server via file share or shared drive
  3. On the server, run the installer as Administrator. Accept all defaults. Click Next through every screen.
  4. Verify in Command Prompt (as Administrator) on the server:
Verify Node.js installed correctly
C:\> node --version
Should print:  v18.x.x

C:\> npm --version
Should print:  9.x.x or 10.x.x
OK
Success

Both commands print a version number. If you see "not recognized", close and reopen Command Prompt and try again.

STEP 2 OF 11

Install IIS URL Rewrite Module 2.1

This IIS add-on routes all web requests to the Node.js application. Without it, every page returns a 404 error.

!
Download on local machine, install on server

The IIS server cannot reach Microsoft's download site. Download rewrite_amd64_en-US.msi on your local machine, copy it to the server, then run it there.

  1. On your local machine, search the web for "IIS URL Rewrite 2.1 download" and download the x64 English installer (rewrite_amd64_en-US.msi) from the Microsoft IIS downloads page
  2. Copy the .msi file to the IIS server via file share or shared drive
  3. On the server, run the installer as Administrator. Accept the license and click Install.
  4. After installation, restart IIS:
C:\> iisreset
Should print:  Internet services successfully restarted
STEP 3 OF 11

Install iisnode

iisnode is the bridge between IIS and Node.js. It lets IIS host Node.js applications the same way it hosts .NET applications.

!
Download on local machine, install on server

The IIS server cannot reach GitHub. Download iisnode-full-v0.2.26-x64.msi on your local machine, copy it to the server, then run it there.

  1. On your local machine, go to github.com/Azure/iisnode → click Releases → download iisnode-full-v0.2.26-x64.msi
  2. Copy the .msi file to the IIS server via file share or shared drive
  3. On the server, run the installer as Administrator. Accept all prompts.
OK
How to confirm iisnode is installed

Open IIS Manager → click the server name at top of left panel → double-click Handler Mappings in the center. Look for an entry named iisnode.

STEP 5 OF 11

Build and Copy node_modules

!
The IIS server has no internet access

The server is a zero-trust machine and cannot reach npmjs.com or any Artifactory. You must run npm install on your local VCSE machine and copy the result to the server.

5a — Run npm install on your local developer machine

Open Command Prompt or PowerShell on your local machine (not on the server):

C:\> cd C:\path\to\bruno-devweb-converter

C:\path\to\bruno-devweb-converter> npm install --production
Takes 1-3 minutes. Wait for "added NNN packages" message at the end.
i
Match the Node.js version

Run node --version on both machines first. They must both be Node.js 18. If versions differ, the native module better-sqlite3 will fail to load on the server.

5b — Copy node_modules to the IIS server

Transfer the entire node_modules folder from your local machine to the server using a file share, SFTP, or shared drive:

Copy FROM your local machine:
  C:\path\to\bruno-devweb-converter\node_modules\

Copy TO the IIS server:
  D:\MSINetData\WWW\converter\node_modules\
!
node_modules contains tens of thousands of small files

Copying over a network share can take several minutes. Do not interrupt the transfer. Wait until your file transfer tool reports it is complete.

OK
Success

D:\MSINetData\WWW\converter\node_modules\ exists on the server and contains many subfolders (express, multer, better-sqlite3, etc.).

PerfX Studio has an Admin Dashboard showing usage analytics — who used which tools, error counts, peak times, and more. It is protected by a password set as an IIS environment variable. The password never appears in any file, URL, or browser history.

STEP 9 OF 11

Set File Permissions

IIS runs as NetworkService. It needs read permission on the application folder and write permission only on the iisnode log subfolder.

Run all three commands in Command Prompt (as Administrator)
-- Read permission on the application folder
C:\> icacls "D:\MSINetData\WWW\converter" /grant "NetworkService:(OI)(CI)R"

-- Create the iisnode log folder
C:\> mkdir "D:\MSINetData\WWW\converter\iisnode"

-- Write permission on log folder only
C:\> icacls "D:\MSINetData\WWW\converter\iisnode" /grant "NetworkService:(OI)(CI)F"
!
Write access only on the iisnode subfolder

Do not grant write access to the entire application folder. Only iisnode\ needs it for log files.

REFERENCE

Updating the Application

When a new version is released, the ADMIN_TOKEN set in IIS persists automatically — no need to set it again.

  1. Copy all updated files from the "Files to Deploy" list into D:\MSINetData\WWW\converter\, replacing existing files
  2. If package.json has changed: run npm install --production on your local machine and copy the updated node_modules\ to the server (same as Step 5). Skip this if no new dependencies were added.
  3. On the IIS server, recycle the app pool to load the new code:
-- Run on the IIS server -- no IIS restart needed
C:\> %windir%\system32\inetsrv\appcmd recycle apppool /apppool.name:"perfx-studio-pool"

Troubleshooting

What you seeMost likely causeFix
502 Bad GatewayNode.js failed to startCheck D:\MSINetData\WWW\converter\iisnode\app.js-xxxxx.txt. Also run node app.js from the app folder to see the error.
404 Not FoundURL Rewrite not installed or web.config missingConfirm web.config is in D:\MSINetData\WWW\converter\. Confirm URL Rewrite installed (Step 2). Run iisreset.

Blank page, no errornode_modules missing or incompleteOn your local machine, run npm install --production, then copy the node_modules\ folder to D:\MSINetData\WWW\converter\ on the server (Step 5). The server cannot run npm install itself.
